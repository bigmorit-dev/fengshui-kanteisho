# デザイン仕様

地理風水鑑定書のビジュアルアイデンティティ。既存の占い系鑑定書ブランドと統一感を持たせる。

## カラーパレット

| 用途 | カラーコード | 備考 |
|---|---|---|
| ベース背景 | `#FBF9F3` | アイボリー |
| メインアクセント | `#5B7C9D` | ダスティブルー |
| メインアクセント(濃) | `#3E5A76` | 見出し・罫線 |
| サブアクセント | `#C9A66B` | ゴールド系（吉方位・重要行の強調） |
| 凶方位・注意喚起 | `#B4695A` | テラコッタ（きつい赤は使わない） |
| 本文テキスト | `#2E2A24` | 黒に近い焦茶 |
| 罫線・枠 | `#D8CBB0` | ベージュ |

## 装飾モチーフ

- **唐草風装飾枠**: ページ上下または表紙全体に、細い蔓草パターンをSVGで配置。線幅1px、色は `#C9A66B` を20%透明度程度で薄く。主張しすぎない。
- **重要メッセージボックス**: 背景 `#5B7C9D` の8%程度の淡色帯 + 左ボーダー4px `#5B7C9D`。開運行動プランや総合アドバイスなど、依頼主に一番伝えたい一文はここに入れる。
- **セクション見出し**: 上に細い罫線、和文フォントの明朝体を使用し、番号（①②③…）を丸囲みで添える。

## タイポグラフィ

- 見出し: Noto Serif CJK JP（明朝体、格式・信頼感を出す）
- 本文: Noto Sans CJK JP（可読性重視）
- 表紙タイトルのみやや大きめ（28-32pt相当）、本文は11-12pt相当

## レイアウト原則

- 各分析セクションは「図（方位盤・簡易イメージ図）＋要素表＋解説文」の三点セットを基本とする
- 表は罫線を最小限にし、ゼブラ縞ではなく行間の余白で区切る（圧迫感を避ける）
- スコア表示（エネルギーバランス）は横棒グラフ。バーの色はスコアに応じて変えない（すべて同じダスティブルー系）— ネガティブな数値評価に見えすぎないようにするため
- ページ番号はフッター中央、小さく控えめに

## ブランディング上の注意

- **鑑定士名・系譜名は本文・表紙のいずれにも一切表示しない。** クレジット欄は「鑑定士」または依頼者が指定するブランド名/屋号のみを表示する。系譜情報はスキル側の内部知識としてのみ保持し、出力物には反映しない。
- ロゴや屋号を入れたい場合は、生成時にプレースホルダーとして受け取り差し替え可能にする。
